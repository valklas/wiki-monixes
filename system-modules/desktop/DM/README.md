# Display Manager Modules

Display-manager modules use the `monixes.system.desktop.DM` namespace.

## Available modules

- [greetd-tuigreet](greetd-tuigreet.md) — Configure the greetd display manager with tuigreet.

## Selection

The `displayManager` option defaults to `none`. Select `greetd-tuigreet` to
enable the implementation documented on the [greetd-tuigreet page](greetd-tuigreet.md).
