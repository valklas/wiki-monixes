# Home Manager Modules

Monixes Home Manager modules use the `monixes.home.*` namespace. Import
`monixes.homeManagerModules.default` inside the relevant
`home-manager.users.<name>` module before configuring these options.

## Available modules

- [Theme](theme.md) — Configure the user-session Catppuccin theme.

More Home Manager modules can be added here as the source project grows.
